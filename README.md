# HD Agent 🤖 — تطبيق ذكي لبيع مزارع Hay Day

تطبيق (أندرويد + ويب) يتحدث فيه العميل مع مساعد ذكي (Claude من Anthropic) بأي لغة أو لهجة، ويشتري مزارع Hay Day
من مخزون حقيقي. مشروع مستقل بالكامل: قاعدة بيانات ولوحة تحكم وخادم خاصة به.

## كيف يعمل
- **الدخول بكود:** الإدارة تنشئ أكواداً تبدأ بـ `HD-` من لوحة التحكم (أكواد العملاء). الكود يُربط بأول جهاز يدخل منه
  ولا يعمل على جهاز آخر حتى تفك الإدارة الربط. يبقى العميل مسجلاً دائماً.
- **المحادثة:** الذكاء الاصطناعي يجيب من المخزون الحقيقي فقط، يحسب الإجمالي، ويسأل «متأكد؟». يكفي أن يكتب العميل «نعم».
- **الدفع:** تظهر تفاصيل الدفع، يحوّل العميل ويرسل صورة التحويل فقط. لا يتأكد الدفع إلا بموافقة الإدارة.
- **التسليم:** بعد الموافقة تظهر بيانات المزارع (ID / Password) في التطبيق، ولا تُحفظ في سجل المحادثة.
- **الإدارة:** ترد على أي محادثة من اللوحة، والتحويل للإدارة يحصل فقط عند شكوى أو مشكلة.

## الروابط
- التطبيق (ويب، قابل للتثبيت على الشاشة الرئيسية): `PUBLIC_URL/`
- ملف أندرويد: `PUBLIC_URL/download`
- لوحة التحكم: `PUBLIC_URL` + `ADMIN_PANEL_PATH`

## البنية
```
app/api/app_api.py      واجهة العميل (/app/api): دخول بالكود، رسائل، تأكيد، إثبات الدفع، الطلبات، بيانات المزارع
app/services/chat.py    مسار المحادثة (ذكاء اصطناعي ← ملخص ← تأكيد ← دفع ← تسليم)
app/messenger.py        يحوّل أحداث النظام إلى بطاقات في التطبيق + تنبيهات للإدارة
app/webapp/             تطبيق العميل (HTML/CSS/JS + PWA)
android/                تطبيق أندرويد (WebView) يُبنى داخل Docker بدون Gradle
app/web/                لوحة التحكم
```

## النشر (Railway)
خدمة PostgreSQL مستقلة + خدمة من هذا الفرع (Dockerfile). المتغيرات في `.env.example`.
`APK_KEYSTORE_B64` و `APK_KS_PASS` يوقّعان ملف أندرويد بنفس المفتاح دائماً (احتفظ بنسخة منهما) حتى تعمل التحديثات فوق النسخة المثبتة.
