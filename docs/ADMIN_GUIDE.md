# دليل المشرف — HD农场

## الدخول

1. افتح رابط لوحة التحكم السري.
2. أدخل اسم المستخدم وكلمة المرور.
3. يصلك رمز من 6 أرقام في بوت تيليجرام، أدخله.

## الصفحة الرئيسية

الإيرادات والأرباح (اليوم / 30 يوماً / الإجمالي)، الدفعات بانتظار المراجعة، الطلبات حسب الحالة، المخزون،
المحادثات المحوّلة للإدارة، والتنبيهات. الربح = سعر البيع − التكلفة المسجلة لكل مزرعة.

## المزارع والمخزون

- **مزرعة واحدة:** الاسم، المستوى، المخزن، الصومعة، الأدوات، السعر، العملة، التكلفة (اختياري لحساب الربح)،
  الوصف، Token ID، كلمة المرور.
- **إضافة مجموعة:** املأ المواصفات المشتركة مرة واحدة، ثم ضع كل مزرعة في سطر: `TokenID:كلمة المرور`.
  اضغط «فحص قبل الحفظ» لرؤية الأخطاء والمكرر، ثم «حفظ».
- **ملف CSV:** الأعمدة `name,lvl,barn,silo,tools,price,currency,token_id,password,cost,description`
  (الأساسية: lvl, price, token_id, password).
- **تعديل/تعطيل/حذف:** متاح للمزارع المتوفرة أو المعطلة فقط. المحجوزة والمباعة مقفلة لحماية الطلبات.
  حدد عدة مزارع لتعطيلها أو تفعيلها أو حذفها دفعة واحدة.
- لا يمكن إضافة Token ID مكرر، ولا تُعرض Token ID أو كلمات المرور في اللوحة بعد الحفظ (تظهر مخفية فقط).
- جدول «العروض المتوفرة كما يراها البوت» يجمع المزارع المتطابقة. هذا بالضبط ما يستطيع البوت عرضه.

## المحادثات

- كل محادثات العملاء محفوظة: رسائل العميل، ردود البوت، ردود الإدارة، وأحداث النظام.
- **إرسال رد:** اكتب في المحادثة واضغط «إرسال للعميل». أي رد منك يوقف الرد الآلي لهذا العميل تلقائياً.
- **إعادة الرد الآلي:** زر «إعادة الرد الآلي» في صفحة المحادثة.
- **إيقاف الرد الآلي للجميع:** من أعلى صفحة المحادثات (مثلاً أثناء الصيانة). عندها تُحوَّل كل الرسائل إليك.
- **من تيليجرام:** عندما تُحوَّل محادثة، تصلك رسالة فيها `#c` ورقم العميل. اعمل Reply عليها واكتب ردك
  فيصل للعميل مباشرة.
- تبويب «محوّلة للإدارة» يعرض العملاء الذين ينتظرون رداً بشرياً.

## مراجعة الدفع

1. يصلك إشعار في تيليجرام فيه صورة الإثبات، المبلغ، الوسيلة، ورقم العملية، مع زري «قبول» و«رفض».
   ونفس الدفعة تظهر في «مراجعة الدفع» باللوحة.
2. **تحقق من وصول المبلغ فعلياً في حسابك** ومطابقة المبلغ ورقم العملية قبل القبول.
3. **قبول:** يتأكد الدفع وتُرسل المزارع للعميل فوراً في قائمة واحدة (ID / Password).
4. **رفض:** اختر سبباً أو اكتبه. الافتراضي: يبقى الطلب محجوزاً ويرسل العميل إثباتاً صحيحاً.
   أو فعّل «رفض الطلب بالكامل» لإلغاء الحجز وإعادة المزارع للمخزون.

النظام يمنع: استخدام نفس الصورة أو نفس رقم العملية لطلبين، وقبول نفس الدفعة مرتين.

## الطلبات

- فلترة حسب الحالة أو البحث برقم الطلب أو Telegram ID.
- داخل الطلب: إلغاء أو رفض مع سبب (يُرسل للعميل وتعود المزارع للمخزون)، إعادة إرسال البيانات للعميل،
  إرسال إشعار بالحالة أو رسالة مخصصة.
- إذا فشل التسليم (مثلاً حظر العميل البوت) يبقى الطلب «قيد التنفيذ» والمزارع محجوزة له، ويظهر تنبيه.
  اضغط «تسليم / إعادة محاولة التسليم» بعد أن يفتح العميل البوت.
- الحجز ينتهي تلقائياً إذا لم يرسل العميل إثبات الدفع خلال المدة المحددة، وتعود المزارع للمخزون.

## وسائل الدفع

أضف أي عدد من الوسائل (Binance Pay، تحويل يدوي، أخرى)، ويمكن إضافة أكثر من معرّف لنفس النوع.
لكل وسيلة: الاسم، المعرّف، العملة، التعليمات، وهل يُطلب رقم العملية. يرى العميل الوسائل المفعّلة بنفس عملة طلبه.

## الإعدادات والذكاء الاصطناعي

- **تعليمات إضافية للبوت:** أسلوب الكلام وما يجب أن يركز عليه.
- **معلومات المتجر، الضمان، التسليم، الدفع، أسئلة شائعة:** البوت يجيب من هذه النصوص فقط. ما ليس فيها
  يحوّله للإدارة بدل أن يخترع جواباً.
- **مدة الحجز، أقصى كمية للطلب، أقصى طلبات مفتوحة للعميل.**

## المشرفون والصلاحيات

- **المالك:** كل شيء.
- **مشرف:** كل شيء عدا المشرفين والنسخ الاحتياطي.
- **دعم:** المحادثات، الطلبات، مراجعة الدفع، العملاء — بدون المخزون والأسعار ووسائل الدفع والإعدادات.

اربط Telegram ID لكل مشرف ليستلم رمز الدخول والإشعارات.

## سجل التدقيق

كل عملية حساسة (إضافة/تعديل مزرعة، قبول/رفض دفع، إلغاء طلب، تغيير إعدادات، تسجيل دخول...) تُسجّل
مع الفاعل والوقت وعنوان IP. السجل لا يمكن تعديله أو حذفه.

## النسخ الاحتياطي

نسخة تلقائية يومياً تُرسل للمالك على تيليجرام، ونسخة يدوية من صفحة «النسخ الاحتياطي».
احتفظ بمفتاح `ENCRYPTION_KEY` في مكان آمن خارج الخادم.
